One ripe strawberry, extreme close-up: glossy red skin, pale achenes in
arched rows, dew drops catching the light, green calyx and stem, on dark
slate. Nothing else in the frame — one ingredient, one taste.

`main.py` (stdlib only) copies the pre-drawn `entry.png` to
`$MAKEFUN_OUTPUT_DIR`. The picture is drawn at build time by
`draw_image.py` (PIL).
